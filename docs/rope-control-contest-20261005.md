# ロープスローと捕まえる技の競り合い

2026-10-05 合意。ロープスローも投げ・関節技と同じ扱いにする。

- 通常攻防でロープスローと投げ・関節技・ロープスローが競合する場合、片方を成立前から優先しない。通常のカウンターと各技の成功判定を行う。
- 双方の捕まえる技が成功した時だけ、既存の赤40%・青40%・膠着20%の崩し合いで、一方だけ成立させる。膠着なら双方不成立。
- ロープスローの成立ログは競り合いで勝った場合にだけ出す。
- 成立したロープスローの折り返し・迎撃優先・停止判定・命中地点での停止・ロープ演出は維持する。
- 捕まえる技以外との攻防のルールは今回変更しない。

確認：5つのロープ／捕まえる技の組み合わせについて、双方成功・カウンター不成立に固定したD100全100通りで赤40・青40・膠着20を確認。各色のカウンターも確認。既存の走り・迎撃13項目と実況検証を通過。

さらに以前と同じ32,000攻防を再検証。ロープスロー同士3,200回の主攻撃は赤だけ1,330回、青だけ1,347回、膠着523回。通常カウンターも含むため、この全体比率は崩し合い単独の40/40/20と一致する必要はない。投げ・関節技・ロープスローの両者同時成立は０件。打撃同士の相打ち結果は変更前と一致。

再現：`node scripts/check-rope-control-contest.cjs`

## 同時攻防の実況

追加依頼により、同時攻撃の実況も統合する。両者の技を一つのメッセージで予告し、両方命中は相打ち、片方だけ命中は命中側と相手の失敗、双方失敗は双方の空振りとする。崩し合いは実際の判定メタデータを使い、片方が崩したか膠着かを表現し、競り負けを空振りとは呼ばない。関節技のロープブレイクも区別する。

投げ同士では既存の組み合いフレームを予告として使い、重複予告を追加しない。命中表示からダメージ表示へ進んでも結果の文を維持し、必要なダウン／グロッキーだけ追記する。双方ロープスローで青が勝った場合も、実際に走らされた赤を実況する。既存フレームの位置・ダメージ・ロープ辺・時間は保持し、実況で再判定しない。

確認：同時打撃の相打ち・片方命中・双方空振り、各崩し合いの赤／青／膠着、双方ロープスローの戻る側の色、飛び技の着地失敗、フォール、状態・ダメージ・既存時間の保持。スマホ幅の実画面で相打ち実況を確認。
