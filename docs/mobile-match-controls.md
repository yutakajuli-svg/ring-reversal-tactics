# スマホ試遊UI（2026-10-04）

これは最初の整理の記録。攻撃先選択・走る表示・迎撃の現行仕様は [target-selection-and-interception.md](target-selection-and-interception.md) を参照。

- 前版のように、移動先を選ぶと赤コマ本体が予定地へ表示される。透明な分身は表示しない。
- 予定表示は試合の確定位置を変えない。CPU予約・同時移動・接触判定・相手のすり抜け禁止は従来のルールを使用する。
- 移動予定地の横に元の回転アイコンを表示。移動先は公開前に選び直せる。
- ２マス移動は自動で「移動のみ」を選び、その手では使えない攻撃ボタンを省く。
- 打撃は「打撃・近」（１マス狙い）と「打撃・遠」（２マス狙い）にまとめる。打撃距離を読むルールは変更しない。
- 走るボタンを省き、選択可能なロープ・コーナーへ盤面上に↗の目印を表示。押すとその方向へ走る予約になる。技や通常の移動先を選ぶと変更できる。
- ロープスロー・掴み移動・連れ戻しは、技を押して盤面上の方向を選ぶ。選び直しは技ボタンを再度押す。
- 成立しないフォールはボタンを出さない。
- 赤・青の顔絵とHPを横並びにし、スマホの盤面とコマンドの高さを整理。キャラ絵・背景・ダメージ顔・衝撃演出は承認版を保つ。
- 実況の見出しを公開／移動／攻撃／ダメージ／カウンター／結果などの進行に合わせる。ダイスの詳しい数値は判定ログへ。

確認：320・360・390px幅、コマ本体の予定表示、試合の確定位置を変えないこと、回転と選び直し、２マス移動、打撃の近・遠、盤面からロープ・対角線コーナーへの走行、ロープスローの方向指定、ダウン・グロッキー中の表情と復帰。
