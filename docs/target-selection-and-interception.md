# 盤面の攻撃先選択とロープスロー後の迎撃

2026-10-04 合意分。今後FIX済みの仕様を変更する必要があれば、実装前に相談する。

移動と攻撃を切り替え、攻撃は狙うマス→技カテゴリー→行動決定の順に選ぶ。同じ高さの２マス先は打撃のみ。コーナーの飛び技、高所崩し、場外、掴み移動・連れ戻しは既存仕様を保持する。移動予定はコマ本体で表示し、通常の回転アイコンを保持。移動先と走る先は同じ色、グラデーションなし。走る矢印は廃止し、選択直後だけ「移動」「走る」の吹き出しを表示する。

予告マスは行動に保存し、相手がそのマスにいない場合は当たらない。CPUは未公開のプレイヤー予約を参照しない。

ロープスロー成功時はロープに到達するところまで表示し、戻るか止まるかの80/20判定は次の迎撃予約を公開してから行う。迎撃側の位置は固定し、帰り道の１・２マス先を選ぶ。戻る側は自発的な攻撃を選べない。既存10%のカウンターが成功すれば迎撃を取り消し、通常打撃と同じ90%命中・１ダメージ・体勢判定で反撃する。「カウンター」「かわす」は専用ボタンではなく結果の呼び分け。

ロープで止まれば無傷。迎撃側はタイミングを崩してグロッキー。止まった側は通常移動かロープから走る攻撃を選べる。戻った相手への２マス迎撃が外れた時も追加ダメージなしでグロッキー。１マスの通常ミスにこのペナルティはない。

自分で走った時・ロープスローの到着と出発のロープアニメを保持する。肖像画の位置・色、ダメージ表示の持続、通常技の威力、復帰、リングアウト等は変更しない。

確認：既存のルール確認、`scripts/check-interception.cjs`、スマホでのマス選択・カテゴリー・迎撃操作、到着／出発のロープアニメ、型チェックと静的ビルド。
