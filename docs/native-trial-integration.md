# 立体リング試作版の同時攻防

2026-10-02。新ルールは既存のトップ画面 `/` と `/ring-lab` に実装されています。

公開URL： https://yutakajuli-svg.github.io/ring-reversal-tactics/

## 実装箇所

- `app/ring-lab/page.tsx`：既存試作版の画面、予約・公開、CPUの予約固定、演出。
- `app/ring-lab/ring-board.tsx`：従来の立体リング、選手・ダウン画像、ロープ、コーナー、場外、深度順をそのまま使う描画。
- `lib/simultaneous-rules.js`：双方の攻防をまとめて解決するルール。
- `scripts/check-simultaneous-native.cjs`：実際に画面が使うルールを検証するチェック。

以前の `lib/match-rules.ts` は参照用に残っています。通常の同時攻防では呼びません。設定から開く前版の手動確認では、前版の判定をそのまま使用します。単体HTML版も参照用に残っていますが、試作版の入口を別ページにする方式は廃止しました。

## 操作

緑の盤面マスで移動を予約し、向き・行動・打撃の間合いを選んで「せーので行動公開」。赤の薄い選手と黄色いマスは予約であり、実際の位置は公開まで変わりません。CPUは攻防開始時に予約します。

攻撃時は１マス、移動のみ２マス。相手のマスを通過する移動はできません。ダウン中の１マス移動、関節技の維持・解除・脱出、固定したロープからの戻りも同じ画面で扱います。

場外の同じ高さでは打撃・投げを使えます。関節技・フォールはリング内です。ロープスローは前版と同じく場外にも対応します。コーナーへ上がる移動と、１〜２マス先の低い位置への飛び技も残しています。飛び技は１ダメージ・命中90%、飛ぶ前のカウンターなら中止だけ、飛んで外した場合は低い位置へ着地して自身も１ダメージ・１回休み。

細かい確率と合意済みルールは `simultaneous-trial-rules.md` の表と共通です。追加の威力ボーナスはありません。投げ以外の捕まえる技同士の40/40/20、両者ダウン３回のカウント、ロープ接触位置から中央へ戻る助走は引き続き仮置きです。

## 高所・コーナー・グロッキーの暫定FIX（2026-10-03）

主試遊版 / と /ring-lab に反映。通常回転４方向、移動１／２マス、既存キャラの大きさ・位置、方向選択の盤面ターゲットを保持。

- 正面１マス・高さ差１の打撃を高所崩し、投げを高所落としとして扱う。専用ボタンは増やさない。成功は１ダメージ、周囲１マスの低い空きマスへ落下し、必ずダウン。崩しは場外あり、落としはリング内のみ。仕掛ける方向から相手を越える奥側には落とさない。
- 飛び技成功：受け手１ダメージ＋１マス押し出し＋ダウン、仕掛け手は受け手の元位置へ着地。空振り：自身１ダメージ＋ダウン、狙った相手の周囲１マスへ落下（奥側除外）。単独カウンターで中止：相手周囲へ落下＋ダウン、カウンターそのものの固定追加ダメージはなし。返す側の予約攻撃の結果は別途適用。
- 斜め走行は２本の主対角線（r=c / r+c=6）から対角線上のコーナーに向かう時のみ。自走は走る選手、コーナースローは投げる選手の位置が基準。スローでは相手を対角線の走路へ送り込んでから走らせる。送り込みも仕掛け手のマスを通らない。途中で相手をすり抜けず、占有・交換・交差する経路では手前で止まる。追加４方向の姿は走行演出中だけ、終了後は既存４方向へ戻る。
- 自分からコーナーへ走る手は攻撃なし。ポスト手前のリング内マスで止まり、次の手は通常行動（ロープの自動折り返しをコーナーには適用しない）。相手と逆方向への助走条件を維持。
- 走らされた相手のコーナー激突：ダメージ・ダウンなし。コーナー隣接１マスのリング内空きマスへランダム移動。グロッキーで次の１手は体勢を立て直す。既存の直線コーナースローも同様。新しいグロッキーは発生した手では消費しない。
- グロッキーは立ち状態。移動・回転・通常攻撃不可、固定の１手で解除し体力は回復しない。自動カウンターは可能。ダウンすればグロッキーを解除し、ダウンの復帰ルールに移る。一般攻撃へのグロッキー追加は後日検討。

「高さ１の相手をコーナー上へ乗せる」は今後の候補。今回のFIXに具体的な判定・条件まで含めない。

開始場面に高所攻防・コーナー走行・コーナースロー・グロッキーを追加。前版の手動確認モードは従来のまま。
