# 2026-10-03 合意済みの更新：移動・場外・グロッキー

適用先は主試遊版 / と /ring-lab。以前のルール記述と異なる箇所は、この更新を優先する。

## 掴み・引きずり移動

ダウン／グロッキーの受け手は、自分では移動も回転もしない。行動可能な選手が、同じ高さで上下左右に隣接した受け手を双方同じ方向へ１マス運べる。配置条件を満たせば100％成立し、攻撃やダメージは伴わず、休みを延ばさない。２人の元のマスは障害物にしない。ポストを通る移動、およびリング内から場外への押し出しは禁止。場外からのリングインは専用の連れ戻しを使う。

運ばれたこと自体で状態は解除しないが、受け手の同じ攻防の復帰準備は通常どおり進む。体力０以下なら復帰判定に成功した時だけ立つ。グロッキーは１手で通常状態へ戻る。

## 連れ戻し・帰還スロー

自分がロープ沿いの場外にいて、同じ場外でダウン／グロッキーの受け手に隣接している時、100％で連れ戻せる。自分は隣接するリング内のロープサイド、受け手はそこに上下左右で隣接する空きロープサイドへ配置。角のポストは除外。２人が１マスずつ動く処理とは別で、受け手の配置候補を盤面で選ぶ。復帰準備は止めない。

元気な相手と帰還する場合は、場外から場内へ戻すロープスロー。通常の迎撃判定は保ち、成功した同じ攻防で２人を隣接したロープサイドへ配置する。双方の場外カウントを解除。

## グロッキー

立ったまま次の１手を休む。自分では移動・回転・攻撃不可。自動カウンターは可能だが、追加の攻撃はしない。発生した攻防では休みを消費せず、次の攻防終了で判定なしに解除、体力回復なし。ダウンするとグロッキーを消す。

通常の打撃・投げの既存の体勢崩し確率は維持。成立した時、ダメージ後の体力で状態を決める。

| 体力 | 状態 |
| --- | --- |
| 最大体力の２／３以上 | グロッキー |
| ０より多く２／３未満 | グロッキー30％／ダウン70％ |
| ０以下 | ダウン |

最大体力は各選手の maxHp（初期８）。最大８なら６以上が元気、最大12なら８以上。高所落下・飛び技の空振りなどの必須ダウンは置き換えない。ロープスローでの場外落下は無傷＋グロッキー、コーナー激突も無傷＋グロッキー。赤・青の承認済み専用４方向シートを使用し、通常のサイズ・位置・４方向回転は変更しない。

## コーナーからの飛び技

射程はコーナーから縦横それぞれ２マスまでの有効なマス。各コーナーでリング内８マス、場外７マスが対象（ユーザーの赤い範囲）。場外の外周を越えるマスや他のポストは不可。

命中すると受け手に１ダメージ、攻撃地点からコーナーと反対へ隣接１マス押し出し、必ずダウン。攻撃側は受け手の元位置に着地。押し出しは射程より１マス外へ出てよい。押し出し先が壁等で塞がっている時は受け手をその場でダウンさせ、追加ダメージを加えない。この時は重ならない隣接する射程内のマスへ攻撃側を着地させる。

空振りは自身１ダメージ＋ダウン。単独カウンターで中止された時も落下＋ダウン（カウンター自体の固定追加ダメージなし）。いずれも攻撃側は受け手の周囲１マスかつ元の射程内へ落ち、受け手の奥側は除外する。

フォール可否は受け手の最終位置で判断。場外とロープ接触位置では不可。攻撃と同じ手での自動フォールは追加しない。

## 場外関節・リングアウト

場外フォールは禁止。場外関節技は初回１ダメージまでで、次の行動選択前に自動解除。維持・追加ダメージ・ギブアップ判定は行わない。

各選手の場外滞在を個別に数える。場外へ出た攻防は０、次の同時攻防から１回加算。５攻防が２０カウントという仮ルールで、表示は０／４／８／12／16／20。ダウンやグロッキー、場外関節中でも進む。帰還したら０に戻し、再度場外へ出たら最初から数える。

期限の攻防も移動・帰還を先に解決する。期限に達して場外に残った選手だけがリングアウト負け。同時に両者が期限に達したら両者リングアウトで引き分け。場外の両者ダウンにはリング内の３回ダウンカウントを適用しない。

## 試遊と検証

開始場面に「ロープ際から引きずる」「場外から連れ戻す」「場外カウント16・帰還」「コーナーから場外へ飛ぶ」「赤グロッキー」を追加。CPUも盤面だけを見て掴み移動・連れ戻し・期限前の帰還を選べる。未公開のプレイヤー予約やこれから出るダイスは参照しない。
